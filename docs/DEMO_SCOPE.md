# VEYRA — Showcase v0.2 scope

This is a *new, separate* Android portfolio sample designed around selected VEYRA gameplay ideas. It is **not** the actual P92/P93 game, its source code, or an older APK renamed for display.

## Included and playable
- Redesigned illustrated front-facing character preview, 4 locked hair appearances per gender and 3 skin swatches. This is **original showcase artwork**, not approved P92 character art.
- Randomized character, six elements and talents, year-by-year childhood through later life.
- Age-based events with 3 choices, varied outcomes and a capped 8-decision chronicle.
- Four yearly activities (study, train, work, rest), one per year.
- Friend Rowan, annual social action, bonds and friendship progression.
- Four careers available from age 16; simple skill counters.
- Bag and small market with item prices, purchase validation and rewards.
- Health, coins, renown, year advancement, a preview-adulthood shortcut, offline local autosave and end-of-life.
- Godot headless smoke checks, Android export, verifiable GitHub release.

## Deliberately excluded
Full P92/P93 GDScripts, the modular 160x176 pixel portrait catalog, production NPC art, event illustrations, creatures, narrative library (2,227 events), quests, world economy, complex battles, royal relationships, inheritance simulation, private source branches and production save schema.

## Visual accuracy
The character presentation is more detailed than v0.1, but is *not* a reproduction of the approved game art and is not evidence that the private build's portraits were used in this demo.

## Testing
Automated checks exercise creation, event stages, duplicate actions, aging guards, friends, careers, marketplace and saved-state normalization. Android compilation and APK archive checks happen in GitHub Actions. Physical-device installation, usability and every behavior case still require manual verification.

An APK can be reverse-engineered. It cannot guarantee absolute confidentiality; no private gameplay engine or private art archive is bundled.
