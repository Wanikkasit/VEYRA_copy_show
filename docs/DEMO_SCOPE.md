# What is and is not in this APK

This downloadable game is a **separate limited portfolio slice**, not the complete P92 Android build or a historical release renamed as a demo.

## Playable here
- Begin a life and select one of two character presentations.
- Three simplified hairstyles, an illustrative pixel-style portrait.
- Randomized name, one of six elements, and a talent.
- Child, student, adult, and elder events, with 2–3 choices per event.
- Optional noncombat/peaceful choices; age advancement; a one-tap demo age shortcut.
- Health, currency, renown and bond counters; local autosave; one-life completion.

## Deliberately not published
- Original P92 character portrait image library, source and modular sprite catalog.
- Original full life simulation / relationship / royal / combat implementation.
- The original narrative catalog (2,227 events) and production save schema.
- Original source project, game design notes, internal asset archive and build outputs.

## Security and evaluation boundaries
The public demo is deliberately small. All source files needed to build *this limited slice* are public, and an APK can be inspected. It is **not possible to guarantee that code inside an APK cannot be reverse engineered**. The private game's source and content are not bundled here.

The preview artwork is intentionally simplified and does not represent P92 production portrait quality. The app is an Android debug-signed prototype and has not been verified on every physical Android device. It runs offline and saves only to its local app storage.
